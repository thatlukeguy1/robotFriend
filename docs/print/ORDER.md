# Riley: 3D print order (v1)

7 parts, 1 of each. All files are in millimetres and already lie flat on the bed the way they
should be printed: please don't rotate them.

| File | Size (mm) | Colour | Supports |
|---|---|---|---|
| `head_front.stl` | 98 × 94 × 27 | beige / ivory | none |
| `head_back.stl` | 98 × 126 × 48 | beige / ivory | only under the two flat lugs that stick out (touching the build plate) |
| `face_plate.stl` | 83 × 79 × 1.6 | black (gloss if possible) | none |
| `base_frame.stl` | 150 × 110 × 46 | gold (silk PLA if possible) | none |
| `base_deck.stl` | 150 × 110 × 9.3 | gold | none |
| `drive_disc.stl` | 82 × 82 × 46.5 | gold | none |
| `horn_hub.stl` | 28 × 28 × 4.8 | gold | none |

About 260 cm³ of plastic in all; the biggest part needs a 150 × 110 mm bed.

**Material:** PLA (PETG is fine too).
**Settings:** 0.2 mm layers, at least 3 walls (perimeters), 20 % infill.
**Please don't** enlarge or drill out the small holes: they're deliberately undersized so the
screws cut their own thread.
**Most visible surfaces:** the front of `head_front` and of `face_plate` (they print face-down, on
the bed), so a smooth bed surface there is appreciated.

Thank you!
